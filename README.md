#背景
地球上方开了一道空间裂缝，诸天万族入侵，同时地球灵气复苏，地球人奋起反抗，与万族进行了一场看不见尽头的战争，而你扮演的则是地球的最高指挥官
## 游戏
*以下为大体说明 后面还会写细分*
1. 这是一个类肉鸽塔防游戏
2. 玩家可以选择使用一种主角色 然后每个角色拥有专属技能
3. 游戏里面的时间以 "天数" 为准 每天刚过的时候可以选择一个事件
4.每把游戏的开局拥有两名NPC和一个建筑(随机低品质，可以通过天赋随机到更高品质)(可通过天赋额外携带指定角色，但是等级要重置，可通过天赋开局获得额外等级)
5. 游戏内有多种神器(可通过事件获得提升)，游戏对局内的货币为金币....

### 游戏如何玩？
- *选择游戏难度，选择初始防守地图，获得初始资源，进行一个初始布局
- *每天流程* 每天开始 -> 事件选择 -> 进行事件 -> 获取战利品/升级   
- *敌人流程* 红门出发 -> 特定路径检索触发 -> 路途房屋/-> 玩家
- *战利品*  神器/特殊事件/建筑获取/金币/角色  
- *项目联动* 特定的角色可能对特定的房屋有特殊效果/拥有特殊房间/
- *对局结束* 无限下去,直到主角死亡,但在第100/200/500/1000/2000天获得双倍结算的机会 

#### 关于角色
1. 每个角色的属性都不一样 (攻击力,防御力,血量上限，爆率，爆伤，固定穿透，百分比穿透，当前血量,属性抗性,各种状态抗性/加成，出手速度)，敌人会多一个移动速度
2. 角色在被近身以后会攻击,无论近远，都是照常按照原先数值进行计算
3. 每个主角色有专属技能，1-2个主动技能+多个被动(通过打关获取)(主角熟练度高的时候会获得专属副角色)
4.每个副角色有一个专属被动(可通过各种方式进行融合使一个角色拥有多被动)
5.主角的星级初始在7星(星级在1到10星)(个人认为前五颗星没满则是x星+空星星(x为当前星级)，若已满则每多一颗则星星变金一颗)(通过事件可能提高也可能降低)
//星级相当于是资质和等级一起决定一个角色的强大与否
6.敌人也是只有boss以及部分精英怪才能拥有主动技能，但是保底都有被动，敌人也有星级评定.
7.只有主角有蓝量设定，初始3点蓝，一次主动技能消耗一点，每两秒回复一点，每次战斗开始，蓝量自动回满(可以通过各种神奇天赋增加)，其余的主动技能统统按照CD来设置
8.伤害类型有物伤，法伤(金/木/水/火/土/光明/黑暗)，真伤
//伤害计算公式为攻击力*(100/(100+(防御力-固定穿透)*(1-百分比穿透)))
如果暴击则在上面的运算结果乘以爆伤
如果是属性伤害则把防御力换成属性抗性
9.状态有
(1)致盲:你这次攻击将有百分之33的概率落空,百分之34的概率打中自己,百分之33的概率命中敌人
(2)愤怒:你这次攻击将等额加成愤怒层数
(3)再生:如果这次伤害没有击杀你，将回复等额再生层数
(4)不死:当你受到致命时保留一滴血
(5)中毒:你将每秒遭受等额中毒层数伤害
(6)燃烧:你将每秒遭受等额燃烧层数伤害
(7)减速:你的速度将会等额降低减速层数
(8)加速:你的速度将会等额增加加速层数,当获得加速增幅的时候优先和减速先抵消
(9)晕眩:受到攻击的时候你将会遭受到5帧的晕眩
(10)吸血:攻击后等额层数回血
(11)麻痹:受到攻击后你将失去下次出手机会
(12)护盾：在受到伤害前你将获得等额层数护盾，持续2s后消失
//减速层数不会减少但是要保证敌人的移动速度至少是1
debuff计算公式为{层数*(1-抗性),层数/(2+抗性)}
buff计算公式为{生效层数*加成,层数/2}

##### 关于房间  
1.房间初始都为空房间，空房间不具备阻挡敌人的效果
2.当房间建造建筑后，房间才会根据建筑的效果生效
3.该游戏的相邻指的是↑↓←→，周围则指的是↑↓←→↖↙↗↘八个方向
4.房间建造建筑无需时间，放置建筑即可，房间初始为3*3，有两个神器可以扩展一圈，扩展成4*4和5*5，这两个神器初步设定在第60天和第160天的boss战的战利品里
5.主角房，相当于一个特殊的房间，容纳了主角色，后续获得神器或者天赋的时候，可以加入副角色

###### 战利品
1. 神器 拥有独特功能，解锁上限，提高下限，扩充玩法//每次获得的神器将不会重复，神器并非都是好的，不过好的偏多一点
2. 金币 用于在商人那购买东西
3. 建筑 小概率获得建筑
4. 副角色 小概率获得副角色
5. 事件 小概率获得特殊事件

####### 关于事件
在事件选择前,你可以自由改变人员配置,但是不可以改变房间配置
一天会出现三个事件给你选择，大概率普通战斗，其余都是小概率
事件有普通战斗,精英战斗,商人
休息(全员血量回满),并且可以进行房间融合，训练(无论是副角色还是主角色都可以以此获得经验升级)，房间位置调换(训练和房间融合和房间位置调换只能选一个)//后续可以增加更多选择，我还没想好
随机事件(部分事件需要前置)(在选择随机事件前，并不知道触发了什么事件)(事件有好有坏),一天会出现三个事件去进行选择(可以通过神器或者天赋有获得额外选择)
有的事件只能通过战斗后触发
如果玩家把所有事件都搞完了，将会出现一些可重复出现的水货事件，神器也同理，
{
1.某个角色获得一些经验
2.某个建筑获得一些经验
3.全体回满血
}
每20天空间裂缝大开,将强制进行一次boss战

########关于建筑
1.玩家拥有一个初始的建筑空间袋，里面只允许放一个建筑(用于休息或者是商人那边的建筑融合)(如果未解锁图纸则无法进行合成商人的建筑融合将要花钱)
2.建筑有等级与经验值设定,等级越高效果更好
3.如果建筑所要放置的房间已有建筑，则会进行选择保留当前建筑还是替换建筑，不管怎么选，都有一方建筑会变成对方的养料
4.建筑融合后将会更强
5.建筑图纸将会在卡包获得，部分一次性事件(需满足前置条件)里面也会有特殊的图纸

#########关于商人
商人是诸界中的特殊存在,喜好交易，将有如下几种业务
1.神器贩卖(一次最多卖三件)
2.建筑融合
3.高效训练(比休息的训练效果更好)
4.角色贩卖
5.天才地宝(角色的星级提升)
6.建筑贩卖
7.商人处可以多次购买，只要你有钱，每次购买价格会越来越高

##########关于战斗
1.地图保证了会有路线通向主角房(开始可以先只做一张地图不贪)
2.每个房间敌人只会进一次(存在敌人走的并非最优解的情况(用随机数来判断敌人所选路线))，如果所在房间联通到主角房，敌人将会在经历这个房间的事件后会前往主角房尝试击杀主角(而非绕路)，如果走到了死路，前方的房间所走次数将为会重置为0
3.主角房在左，敌人从右侧进入
//
随机数生成路为这样
1-25为左，26-50为上，51-75为下，76-100为右
此处预设两把神器
惑域幻镜:使敌人更容易走错路
将1-15为左，16-40为上，41-65为下，66-100为右
破障之眼:敌人更容易走正确路
把随机生成的最大数改成75即可
//
4.如果随机到的方向无论可走，将一直随机到有路可走为止
5.副角色在战斗中死亡并非真的死亡
6.每次战斗前血量己方(包括未上场的角色)全部回复血量上限的20%，主角魔量回满(事件或者神器会影响这些)
7.每场战斗结束后根据角色资质获得经验，建筑也会获得经验(全员，全建筑，包括没有上场的)
8.buff并不会叠到下一次战斗
9.一个房间可容纳的敌人无上限，不过个人感觉一场战斗最多生成999名敌人，敌人并不是一帧之内全部生成的，可以五帧生成一敌人

###########关于结算
1.主角死亡会进行结算
2.第100/200/500/1000/2000天获得双倍结算提前结算的机会 
3.结算会根据得分(不同难度和神器和天赋会影响此项)获得魂核和当前主角的熟练度
4.如果有相关天赋，可以带走本局的角色到下一局(但是状态重置，等级和星级重置)


############关于商店
商店有各种卡包，可用源核购买卡包进行抽卡，保证不会出现重复的卡，新的卡会解锁更多神器，更多主角，更多副角，更多种敌人，更多种建筑，建筑融合图纸等物品
可以设置多个卡包(后续维护更新可以把一部分新物品塞到卡包里面抽)

#############关于图鉴
玩家可在里面预览，建筑，主角，副角，敌人，神器，前面四样只显示1级正常资质的属性，也可以适当加一些背景介绍

##############关于难度
可以把难度设置为
新手，普通，棘手，困难，专家，大师，严酷，苦难，传说，神话，深渊
每过一个难度即可挑战下面两个难度，开局可选难度为新手和普通

地图可以分为2类一种是防御地图一种是背景地图
防御地图就是玩家可布置和操控的房间
背景地图就是每局的增益减益
